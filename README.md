# Cybersecurity Resources

A categorized, deduplicated index of learning sites, labs, CTFs, wargames, writeups, and reference material.

## Tagging + Colored Labels (for your website)

Each entry starts with tag chips like `[CTF] [WEB] [BEGINNER]`.

Coloring idea:

- Keep the chips in Markdown and style them in your site with CSS (or transform chips to `<span class="tag tag-ctf">CTF</span>` during your build).

Recommended CSS mapping approach:

- Treat chips as tokens and map to colors by value (examples: `CTF`, `WEB`, `CLOUD`, `OSINT`, `MALWARE`, `BLUE`, `RED`, `ARCHIVE`, `WRITEUPS`, `REFERENCE`, `COURSE`, `LABS`, `WARGAME`, `TOOL`, `FREE`, `PAID`, `ACCOUNT`).

## Index

- Web: web hacking labs, XSS/SQL practice, web academy material
- CTF: active platforms, challenge sites, event hubs
- Wargames & Boot2Root: OverTheWire style, boot2root VM platforms
- Cloud: AWS/Azure/K8s/IAM labs and CTFs
- Pwn & RE: binary exploitation, reversing, asm practice
- Mobile: Android/iOS security labs and practice
- Malware & DFIR: malware analysis, DFIR, PCAPs
- OSINT: OSINT learning and OSINT CTFs
- Blue Team: SOC-focused practice and content archives
- Programming & CS: general coding practice sites useful for security
- University: courseware and lecture pages
- Courses & Certifications: structured learning and cert prep
- References & Lists: cheat sheets, awesome lists, writeups, blogs
